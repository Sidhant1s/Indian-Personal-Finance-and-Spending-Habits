## [1.0.0] - 2026-11-14

### Added
- Project documentation (`Project_Documentation.docx`) covering the overview, dataset description, data dictionary, methodology, key findings and limitations.
- This changelog.
- Problem statement: analyse financial parameters by city tier and occupation.
- Dataset source and licence details: Kaggle, CC BY-SA 4.0, 20,000 records.

### Changed
- Data type of `Dependents` converted from number to string during the process phase.

### Data validation
- Data edited and cleaned in Power Query (Power BI), then checked and confirmed ready for analysis.

### Findings
- Tier 3 has the highest disposable income, followed by Tier 2. Tier 1 has the lowest.
- Professionals pay the most rent, followed by students. Retired individuals pay the least.
- Potential savings are nearly the same across all occupations.
- Tier 2 leads in potential savings for healthcare, transportation, utilities and education. Tier 3 is lowest in each.
